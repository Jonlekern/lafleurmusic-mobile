# LAFLEURMUSIC téléphone — plan 5 « Plex » Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ajouter un compte Plex par un code validé sur plex.tv (pas de mot de passe tapé dans l'appli), puis l'utiliser comme les autres comptes : bibliothèque, lecture, garder, écoutes, playlists.

**Architecture:** `lib/sources/plex.dart` implémente `MusicSource` ; clés `plex://<compte>/<ratingKey>`. La connexion suit le « PIN » de plex.tv : l'appli demande un code, l'utilisateur l'entre sur plex.tv/link, l'appli récupère le jeton, puis choisit le serveur et sa meilleure adresse (réseau local d'abord).

**Tech Stack:** `http` (+ `MockClient`), API plex.tv v2 (pins, resources) et API du serveur Plex Media Server.

**Spec:** spec §2 (Plex en dernier, connexion par code validé), §3 · Maquette : `maquettes/2-coverflow-comptes.png` écran 6 (« Plex · code validé ») et écran 7 (onglet « Plex »).
